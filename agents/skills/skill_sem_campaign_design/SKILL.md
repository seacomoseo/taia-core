# SEM Campaign Design

Create campaign-ready SEM structures with measurable objectives.

## When to Use

- Launching or restructuring paid search campaigns.
- Aligning ads with new offers or landing pages.

## Inputs

1. Keyword groups and persona data.
2. Offer, budget, and conversion goals.

## Process

1. Build campaign and ad-group architecture by intent.
2. Draft ad messaging variants and extension requirements.
3. Define landing page alignment and conversion path.
4. Define tracking events and reporting cadence.

## Outputs

1. `/_context/ads/sem-campaign-structure.md`
2. `/_context/ads/ad-copy-variants.md`
3. `/_context/ads/landing-alignment-checklist.md`
4. `/_context/ads/sem-measurement-plan.md`

## Definition of Done

- [ ] Campaign structure is implementable.
- [ ] Ad variants map to intent and offers.
- [ ] Measurement plan covers core conversion events.
