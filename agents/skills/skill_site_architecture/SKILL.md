# Site Architecture

Design a scalable, intent-aware website structure.

## When to Use

- During planning before heavy page production.
- Existing structure is fragmented or SEO-hostile.

## Inputs

1. Keyword clusters and strategy outputs.
2. Offer and persona outputs.

## Process

1. Define top-level sections and page types.
2. Map URL and breadcrumb hierarchy.
3. Define internal linking hubs and supporting pages.
4. Validate architecture against CMS and content model constraints.

## Outputs

1. `/_context/seo/site-architecture.md`
2. `/_context/seo/url-structure.md`
3. `/_context/seo/internal-linking-blueprint.md`

## Definition of Done

- [ ] Each primary intent has a clear destination page.
- [ ] URL hierarchy is consistent and scalable.
- [ ] Internal linking plan supports discovery and authority flow.
