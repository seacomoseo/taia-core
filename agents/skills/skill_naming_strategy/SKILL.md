# Naming Strategy

Create naming options that are memorable, positioned, and practical.

## When to Use

- New brand/product/service naming.
- Rebrand or repositioning projects.

## Inputs

1. Positioning statement and audience.
2. Language and market constraints.

## Process

1. Define naming criteria: tone, memorability, pronounceability, semantic fit.
2. Generate multiple naming territories and candidates.
3. Score candidates with a transparent matrix.
4. Recommend shortlist and fallback options.

## Outputs

1. `/_context/brand/naming-criteria.md`
2. `/_context/brand/naming-candidates.md`
3. `/_context/brand/naming-shortlist.md`

## Definition of Done

- [ ] Candidate set is varied and intentional.
- [ ] Scoring matrix is explicit and repeatable.
- [ ] Final shortlist includes rationale.
