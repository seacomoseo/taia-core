# Content Planning

Plan what content to produce, why, and in what order.

## When to Use

- After strategy and keyword mapping.
- Before writing or building templates at scale.

## Inputs

1. Site architecture and keyword map.
2. Copy style and offer strategy.

## Process

1. Define page-level content requirements for each template.
2. Build editorial backlog by funnel stage.
3. Define content briefs and acceptance criteria.
4. Prioritize by impact and production effort.

## Outputs

1. `/_context/content/page-content-spec.md`
2. `/_context/content/editorial-backlog.md`
3. `/_context/content/content-brief-template.md`

## Definition of Done

- [ ] Each page type has required content blocks.
- [ ] Backlog is prioritized and stage-aware.
- [ ] Brief template is reusable for future iterations.
