# Copy Style Guide

Create a practical copy system that keeps messaging consistent across channels.

## When to Use

- Brand tone is undefined or inconsistent.
- Multiple contributors will write content.

## Inputs

1. Brand identity and persona docs.
2. Existing website/ad copy samples.

## Process

1. Define voice attributes and anti-patterns.
2. Define messaging hierarchy (promise, proof, CTA tone).
3. Create templates for hero, service sections, FAQs, ads, and emails.
4. Add language-specific notes for ES/EN consistency.

## Outputs

1. `/_context/brand/copy-style-guide.md`
2. `/_context/brand/copy-templates.md`
3. `/_context/brand/messaging-do-dont.md`

## Definition of Done

- [ ] Voice system is explicit and reusable.
- [ ] Templates are directly usable by content and ads skills.
- [ ] Do/Don't examples are included.
