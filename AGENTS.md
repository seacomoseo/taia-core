# TAIA Core - Agent Guide

## Project Structure

- `../content/` - Content collections and settings
- `../templates/` - Page templates (`.astro`), editable in CMS
- `../components/` - UI components (`.astro`), editable in CMS
- `../uploads/` - Media uploads served from `/uploads`

## Content & CMS

- Site config lives at `../content/settings.yml`
- Collections and singles are defined in `../content/settings.yml`
- Each collection supports `singular` and `icon` metadata for CMS/UI
- Collection prefixes are defined per-language in `../content/<collection>/_index.<lang>.md` using `path` without a leading slash
- Collection landing pages use `slug` in `_index.<lang>.md`
- Home lives in `../content/singles/_home.<lang>.md`
- Default language is the first entry in `languages`
- Non-default languages are prefixed in URLs: `/<lang>/...`
- CMS config is served at `/admin/config.yml` (fingerprinted)
- When the system changes, update docs and rules in this repo

## i18n

- Translatable strings live in `content/i18n/<lang>.yml`
- CMS fields support `i18n: true` for localized values
- Use `@core/utils/i18n` helpers in templates/components

## Content Config

- `content/config.ts` is a thin wrapper that loads the virtual module `virtual:taia-content-config`
- The virtual module is generated by the core integration from `content/settings.yml`

## Favicon

- Favicon source configured via `content/settings.yml`
- The app serves `/favicon.ico`, `/favicon.png`, and `/favicon.svg` (if SVG source)
- HTML includes the required favicon link tags
